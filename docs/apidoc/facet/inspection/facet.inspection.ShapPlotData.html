facet.inspection.ShapPlotData#

class facet.inspection.ShapPlotData(*, shap_values, features, target)[source]#

Data for use in SHAP plots provided by the shap package.

Parameters:

  • shap_values (Union[ndarray[tuple[int, ...], dtype[float64]], list[ndarray[tuple[int, ...], dtype[float64]]]]) – the shap values for all observations and outputs

  • features (DataFrame) – features for which SHAP values are available; aligned with param shap_values

  • target (Union[Series, DataFrame]) – target values for all observations; aligned with param shap_values

Attribute summary

features

Matrix of feature values (number of observations by number of features).

shap_values

Matrix of SHAP values (number of observations by number of features) or list of shap value matrices for multi-output models.

target

Series of target values (number of observations) or matrix of target values for multi-output models (number of observations by number of outputs).
